**Codewars:** [6 kyu — Multiples of 3 or 5](https://www.codewars.com/kata/514b92a657cdc65150000006)
<br>
**Solution Language:** Python

## Description

Write a function that returns the sum of all the natural numbers below a given number that are multiples of 3 or 5.

For example, given `10`, the multiples are `3`, `5`, `6` and `9`, whose sum is `23`.
