# Multiply adjacent digits

**Codewars:** [7 kyu — Multiply adjacent digits](https://www.codewars.com/kata/67191920c29c7e09d9f40707)
<br>
**Solution Language:** Python

## Description

Multiply the adjacent digits which are not separated by a '-' or a '+' in a string, then do the sum.
Examples

"53+5"    -->   20  # = 5 * 3 + 5
"266-66"  -->   36  # = 2 * 6 * 6 - 6 * 6
"555"     -->  125  # = 5 * 5 * 5
