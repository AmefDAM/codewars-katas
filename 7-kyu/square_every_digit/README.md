# Square Every Digit

**Codewars:** [7 kyu — Square Every Digit](https://www.codewars.com/kata/546e2562b03326a88e000020)
<br>
**Solution Language:** Python

## Description

Write a function that squares every digit of a given number and concatenates the results.

For example, `9119` becomes `811181` because `9² = 81`, `1² = 1`, `1² = 1` and `9² = 81`.
